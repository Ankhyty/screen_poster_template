## 🛠️ 三大核心问题深度解决说明

### 1. 彻底解决导出时“显示跨域错误”的问题
- **根因分析**：在浏览器直接以 `file:///` 协议打开本地网页时，Chromium 安全策略会将本地相对路径引用的图片视为不同源，导致 Canvas 画布被“污染（Tainted）”，调用 `toDataURL()` 时抛出安全异常。
- **终极解决方案**：我们将海报默认封面及两张群二维码提前在 `assets/js/default-assets.js` 中转为 **Base64 Data URL**，并在文件上传中使用 `FileReader.readAsDataURL()`。在绘图导出过程中，**100% 的图像数据均为同源 Base64 格式**，彻底根除跨域报错，保证任何环境下点击导出均能 100% 秒级下载！

### 2. 现代开放式构成主义 (Modern Constructivist Open Grid) 先锋排版
- **视觉渊源**：融合 1920~1930 年代苏联构成主义大师 **罗德琴科 (Rodchenko)** 的赤黑几何张力与现代瑞士国际主义平面（Swiss Open Grid）的通透质感。
- **全新升级特色**：
  - **语言全英文化与专业核对**：移除所有生僻俄文，全面采用标准、地道的电影展映英语：
    - 顶部横幅：`CAC.ANIME × EIZOUKEN` / `SPECIAL PREMIERE // JOINT SCREENING`（原版俄文 `ПРЕМЬЕРА // 联合放映会` 之典雅英译）
    - 左栏：`SYNOPSIS // 剧情梗概 & 看点`（纯净单一栏目，保持开放通透）
    - 栏目 01：`TIME // 放映时间`（原版 `ВРЕМЯ`）
    - 栏目 02：`VENUE // 活动地点`（原版 `МЕСТО`）
    - 栏目 03：`TIPS // 参会须知`（忠实继承并规范原版标注的 `Tips`）
    - 栏目 04：`COMMUNITY // 扫码加入`（原版 `СВЯЗЬ` 社群联络之专业英译）
    - 底栏：`SPECIAL SCREENING`（原版 `ПРЕМЬЕРНЫЙ ПОКАЗ` 特映字标）
  - **左栏字型饱满舒展（拒绝冗余栏目）**：
    - 严格保持「剧情梗概 & 看点」单一栏目，不擅自增设多余版块；
    - 字号升级至 `13.5px`，行高设为宽松大气的 `1.85`，字间距 `0.4px`，文字流动舒展自然，填满空间的同时保持纯净的人文阅读质感。
  - **右栏竖线统一加粗（规范统一的赤黑韵律）**：
    - 右栏 01（放映时间）与 02（活动地点）左侧竖线统一为一致的**苏维埃赤红（Soviet Red）**，彻底消除原先颜色不一造成的混乱感；
    - 竖线加粗至 **`4px solid var(--soviet-red)`**，视觉锚点沉稳有力；
    - 序号方块：采用醒目的**赤红印章方块（`01` `02` `03` `04`）**；
    - 参会须知：采用**先锋赤红几何实心方块 `■` 列表符**；
    - 二维码专区：引入**赤红硬核细轮廓与黑底白字印章标签**，形成鲜活的视觉跳跃感。
  - **大标题单占首行，中缝立柱分割**：
    - 主标题独占首行，无书名号《》，字重磅礴；副标题与类型印章标签规整排列在次行；
    - 左右两栏之间的垂直中轴分割线加粗至 **`3px solid var(--soviet-border)`**，分界坚固利落，彻底消除横线交错打架的混乱感。
