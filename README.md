## 🛠️ 三大核心问题深度解决说明

### 1. 彻底解决导出时“显示跨域错误”的问题
- **根因分析**：在浏览器直接以 `file:///` 协议打开本地网页时，Chromium 安全策略会将本地相对路径引用的图片视为不同源，导致 Canvas 画布被“污染（Tainted）”，调用 `toDataURL()` 时抛出安全异常。
- **终极解决方案**：我们将海报默认封面及两张群二维码提前在 `assets/js/default-assets.js` 中转为 **Base64 Data URL**，并在文件上传中使用 `FileReader.readAsDataURL()`。在绘图导出过程中，**100% 的图像数据均为同源 Base64 格式**，彻底根除跨域报错，保证任何环境下点击导出均能 100% 秒级下载！

### 2. 真正原汁原味的苏联构成主义 (Soviet Constructivism)
- **视觉渊源**：参考 1920~1930 年代苏联先锋艺术大师 **罗德琴科 (Rodchenko)** 与 **斯坚伯格兄弟 (Stenberg Brothers)** 的电影海报风格。
- **纯正视觉符号**：
  - **色彩张力**：苏维埃赤红 (`#d90429`)、先锋浓墨黑 (`#111215`) 与做旧报纸米黄底 (`#f2ede4`) 形成剧烈对比。
  - **顶部先锋横幅**：经典红色契形箭头与粗旷大写字标 `CAC.ANIME × EIZOUKEN // ПРЕМЬЕРА`。
  - **双列几何日程网格**：`ВРЕМЯ`（时间）与 `МЕСТО`（场地）红黑方块冲撞，排版沉稳硬朗。
  - **印章式方块标签**：`[ 剧场版 ]`、`[ 奇幻青春 ]` 如苏维埃木刻印章般嵌在剧名后。
  - **参会须知**：`★ ВНИМАНИЕ // 参会须知 & 观影备忘` 标语式通告栏。

### 3. 封面图“只缩放适配，绝不裁切”

- 无论上传 16:9 横版剧照还是 3:4 / 2:3 官方竖版海报，画面均**完整等比例缩放居中呈现**，绝对不会截断人物头部或任何边角细节！
